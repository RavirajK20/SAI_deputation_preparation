# SAI Divisions — One-Line Recall Sheet

*Goal: reconstruct SAI's organisation from memory in 60–90 seconds. Source: Module 1 (verified directly from SAI's live Divisions tab).*

| Division | Remember it as |
|---|---|
| TEAMS | Preps national teams for international events with NSFs, on behalf of MYAS |
| TOPS | Targeted support for identified Olympic/Paralympic medal prospects, funded via NSDF |
| IT | NSRS, Khelo India app, e-Office, SPARROW, and SAI's data-analytics/AI-ML "sports intelligence" function |
| Sports Science | Physiology, biomechanics, nutrition, psychology support for athletes |
| Stadia | Runs/maintains SAI's 5 Delhi stadia (JNS, IGSC, SPMSPC, MDCNS, KSSR) |
| Engineering | Sports infrastructure planning, construction, maintenance |
| Capacity Building | Training/development for SAI's own staff and coaches |
| Finance | Budgeting, fund release, GFR compliance, PFMS |
| Coordination | Nodal point for MYAS liaison, Parliament questions, RTI |
| GAD & Procurement | Goods/services procurement, contracts, vendor management |
| Legal | All legal matters pertaining to SAI |
| Vigilance | Integrity/vigilance matters |
| Media | Press, NIT/ad releases, cultural-exchange liaison |
| Rajbhasha | Official Language Act implementation |
| Khelo India | KICs, KISCEs, talent ID, academy accreditation, funding/UCs |
| Operations | Runs the NCOE/STC/Extension Centre/NSTC scheme machinery day to day |
| HR | Recruitment, service matters, deputation |
| Policy/Research & Innovation | Research, evaluation, systemic-gap analysis, benchmarking |
| TAGG | Target Asian Games Group — athlete preparation specifically for Asian Games cycles |

**Note:** AR 2023-24's org chart groups some of these slightly differently ("Personnel Division" instead of "HR", no standalone IT/Policy-Research/TAGG divisions listed) — reflects genuine restructuring between 2023-24 and now, not an error. See Module 6.
