# Animated Chapters

Short painterly/illustrated animated adaptations of "The Long Run" (see `../11-story/`). Produced
as a separate, later-stage project on top of the locked story text — narration and on-screen facts
trace back to the same canonical `11-story/index.html` content, with no invented institutional
claims. See `PRODUCTION_STATUS.md` in this folder for the full current status, known limitations,
and production method.
