Evidence Architecture

What India's public sports-development records can, and cannot, establish about the relationship between government support and international competitive outcomes — a source-disciplined analytical record, presented for review.
India runs one of the world's largest public athlete-support systems. This is what its public records can establish — and, with equal rigor, what they currently cannot.
00 — The Question

What does India's sports-development system need to know about itself?

Public expenditure, infrastructure sanctions, athlete-support records, and competitive results are all published, separately, by different parts of the system. This project assembled them into one evidence base, under strict source-tier and provenance discipline, and asked one question: how far can that evidence be pushed before it stops being able to answer the question it was built to answer?

07 — The Analytical Test

What happened when the frozen rules were actually applied

Even where a co-occurrence had been confirmed, it would be confounded: athletes already on a medal-contending track are more likely to receive TOPS-family support in the first place. Nothing in this evidence base can separate "support contributed to the outcome" from "the athlete was already on a trajectory that attracted both."

09 — The Data Architecture Insight

What would make the next question answerable

General data-design principles only — never a claim about what SAI's or MYAS's actual internal (non-public) systems contain, since no authoritative source in this evidence base establishes that.

A record that captured…

  • An actual disbursement date, not only a snapshot-export date, would make timing analysis possible.
  • A shared identifier across infrastructure registers would remove the need for heuristic text-matching.
  • A consistent accounting stage field at the point of data publication would remove the 35% currently left AMBIGUOUS.
  • A common event-level key linking a support record, its financial stage, and a competitive outcome for the same intervention would make longitudinal analysis possible for the first time.

Current vs. desired architecture

Current public evidence

Fragmented, cross-sectional, snapshot-dated records across independently-published sources.
↓

Desired analytical architecture

Longitudinal, linked records with persistent identifiers and provenance preserved at every stage: enrolment → support → financial stage → training/ competition exposure → outcome.
